- **Spec-Driven Development** com GitHub Spec Kit (constitution, specs, planos e tarefas antes do código)
- **Agentes de código** (Claude Code, Antigravity) supervisionados para refatoração, documentação e organização de repositórios
- **MCP (Model Context Protocol)** — servidor MCP em Python integrando Azure AI Foundry ao VS Code, e uso de MCPs para Notion, Supabase, Vercel e Railway
- **Context engineering** — `CLAUDE.md`, constitutions e prompts estruturados para mudanças incrementais e reversíveis
